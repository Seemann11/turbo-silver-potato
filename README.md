# Веб-приложение «Bobr» — Сервис приюта для животных

Полнофункциональное веб-приложение (Fullstack SPA) для автоматизации подбора домашних животных из приюта, подачи электронных заявок на усыновление и управления карточками питомцев.

Ссылка на макет Figma: https://www.figma.com/design/mUXjYdJPXwDgqbOKhBo9G3/S?node-id=0-1&t=B47CESYf9hsUmNLx-1
---

## Технологический стек

### Фронтенд
* **Framework:** React (Vite) + TypeScript
* **Стилизация:** Tailwind CSS (Адаптивная верстка, подход Mobile-First)
* **Анимации:** Swiper.js (слайдеры), AOS / Framer Motion (анимация при скролле)

### Бэкенд & База данных
* **Сервер:** Node.js
* **База данных:** PostgreSQL
* **ORM:** Prisma (миграции, моделирование данных, seed-скрипты)
